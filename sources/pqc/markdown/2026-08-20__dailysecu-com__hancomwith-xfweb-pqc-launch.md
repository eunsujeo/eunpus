## 레거시 시스템 변경 최소화해 양자내성암호 체계 도입 지원

한컴위드가 사용자가 별도의 보안 프로그램을 설치할 필요 없이 웹 통신 데이터를 보호하는 무설치 기반 차세대 보안 솔루션 한컴 엑스에프웹(Hancom xFWeb)을 출시했다.

한컴 엑스에프웹은 고객사의 시스템 변경을 줄이면서 웹 애플리케이션 영역에 적용할 수 있도록 설계된 솔루션이다. 사용자는 EXE 방식의 별도 프로그램 설치 없이 웹 표준 기반으로 이용할 수 있어 보안성과 편의성을 동시에 확보하게 된다.

이 솔루션은 암호 민첩성 기반 설계를 적용해 기존 레거시 시스템의 복잡도와 노후화에 따른 시스템 오작동, 교체 비용 부담을 낮췄다. 시스템 수정을 최소화하면서 안전하게 PQC 체계로 전환할 수 있도록 지원하는 방식이다.

계층형 PQC 하이브리드 방식을 채택한 점도 특징이다. 기존 TLS 보안 채널 위에 애플리케이션 계층의 PQC 암호 통신을 더하는 구조로, 인프라 전반을 교체하지 않고도 양자컴퓨터 해킹 위협에 대응할 수 있다.

최근 국내 웹 시스템 해킹 사고의 주요 원인으로 지목되는 파라미터 위·변조 공격에 대한 방어 기능도 갖췄다. 한컴 엑스에프웹은 AEAD 기반의 데이터 무결성 검증 기술을 통해 전송 구간에서 발생할 수 있는 웹 위·변조 취약점과 스크래핑, 봇 공격을 차단한다. 스크립트 난독화와 무결성 자가 검증 기술을 적용해 외부의 코드 분석과 변조 시도에도 대응한다.

한컴위드는 정부의 설치형 보안 소프트웨어 단계적 제한 방침과 암호 체계 전환 요구에 맞춰, 규제 준수와 보안을 동시에 해결해야 하는 공공 및 금융 분야를 중심으로 공급을 늘릴 계획이다.

송상엽 한컴위드 대표는 "무설치 보안 환경과 양자내성암호 전환은 공공과 금융 시장에서 중요한 과제로 부상했다"며, "암호 민첩성을 확보할 수 있는 솔루션을 기반으로 변화하는 보안 정책과 시장 흐름에 대응하겠다"고 밝혔다.
