# 트래블룰 알아보기 — 업비트 이용자 가이드

업비트는 100만원 이상의 입출금 건에 대하여 트래블룰을 준수하게 됨에 따라 트래블룰 솔루션 연동 가상자산사업자, 계정주 확인이 가능한 가상자산사업자 그리고 등록된 개인지갑 주소에 한하여 출금이 가능합니다.

## 트래블룰 시행 후 디지털 자산 출금 방법

원화 환산가 100만원 미만의 디지털 자산은 별도 안내 문서를 확인. 원화 환산가 100만원 이상의 디지털 자산을 출금 시 아래와 같이 진행:

### 트래블룰 연동 가상자산사업자로 출금하는 경우
- **개인 회원**에게 출금 시 [거래소] 선택 및 [받는 사람 이름] 을 입력해야 하며 해당 거래소의 수취인 계정 정보와 일치해야 출금 가능.
- **법인 회원**에게 출금 시 [거래소] 선택 및 [법인명 및 대표자 이름] 을 입력해야 하며 해당 거래소의 수취인 계정 정보와 일치해야 출금 가능.

### 계정주 확인 연동 가상자산사업자로 출금하는 경우
- 입금받을 거래소를 선택 후 업비트 계정주와 입금받을 계정주가 동일인임이 확인되면 출금됨.

### 회원 본인의 개인지갑으로 출금하는 경우
- 업비트에 등록한 개인지갑에 한하여 자유로운 출금 가능.
- 지원 개인지갑: 메타마스크, 카이아, 팬텀, 폴카닷, 케플러.
- 메타마스크는 PC 웹과 모바일 앱(안드로이드/iOS)에서 등록 가능. 카이아·팬텀·폴카닷·케플러는 PC 웹에서만 등록 가능.

## 트래블룰 시행 후 디지털 자산 입금 방법

원화 환산가 100만원 미만의 디지털 자산은 기존과 동일하게 입금 가능.

### 100만원 이상 — 추가 확인이 필요 없는 경우
- **트래블룰 연동 가상자산사업자에서 입금된 경우**: 별도의 추가 확인 없이 입금 반영.
- **회원 본인의 개인지갑에서 입금된 경우**: 별도의 추가 확인 없이 입금 반영. 단, 본인의 개인지갑주소를 등록하기 전에 입금된 건은 개인지갑 등록 후에 입금 반영.

### 100만원 이상 — 추가 확인이 필요한 경우
- **계정주 확인 연동 가상자산사업자에서 입금된 경우**: 입금 대기 건의 [추가확인] 버튼으로 계정주 확인 서비스 절차 진행 — 송금인과 수취인이 동일인임이 확인되면 입금 반영.
- **위험평가 통과 해외 가상자산사업자에서 입금된 경우**: 개인 회원에 한하여 별도의 소명 절차(입금 출처 확인)를 통해 동일 소유주의 계정 간 입금 건임이 확인되면 입금 반영 가능.

## 주의사항

- 트래블룰 이행 시점 이후, 업비트 싱가포르·인도네시아 대상 "바로 출금"은 제한. 업비트 한국 내 회원간의 바로 출금은 기존과 동일하게 지원.
- Open API를 통한 디지털 자산 일반 출금은 등록된 출금 주소로만 가능. 2022년 8월 8일 이후 기존에 등록된 출금주소로는 출금 불가 — 신규 출금주소 등록 후 이용.
- 트래블룰 미준수 입금 건은 입금 반영 불가 — 입금 반환 절차로 반환 신청 접수.
- 100만원 미만의 입출금이 반복적으로 발생하는 경우, 이상입출금으로 간주되어 입출금이 반려될 수 있음.
