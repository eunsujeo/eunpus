# 람다256, 케이뱅크·케이에스넷과 디지털자산 정산 오프램프·AML 검증 프로젝트 착수 (이투데이)

> source: https://www.etoday.co.kr/news/view/2600883
> fetched: 2026-08-20 (WebFetch 추출 — 요약 정리)

- 람다256·케이뱅크·케이에스넷(KSNET) 3사가 디지털자산 오프램프 및 온체인 AML·FDS 기술검증 (PoC) 착수. 약 5개월 공동 실증. 토큰은 USDC.
- 역할 분담:
  - **케이뱅크** — 환율(FX) 적용, 원화 지급, AML/STR 운영 체계
  - **케이에스넷** — 결제 인프라 제공, 가맹점 대상 원화 정산, 실물 비즈니스 운영 정책 검증
  - **람다256** — SCOPE (온체인 정산) + CLAIR (온체인 컴플라이언스) 플랫폼 기술 지원
- 검증 흐름: 결제 시점의 FX 적용 → 대금 정산 요청 생성 → AML·FDS 검증 → 지급 승인 → 온체인 정산 실행 → 원화 지급 → 거래 모니터링·의심거래보고(STR)
- 운영체계 점검: 참여 기관 간 역할 분담, 컴플라이언스, 감사 대응, 정책 유연성
- 지갑·키 관리 상세는 기사에 없음
