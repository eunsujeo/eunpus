# sources/fireblocks/images/

다이어그램·스크린샷·로고 등 이미지 자산.

## 파일명 규칙

`YYYY-MM-DD__<source-stem>__<short-desc>.png`

예시:
- `2024-09-12__fireblocks-mpc-cmp-whitepaper__architecture-diagram.png`
- `2026-05-18__docs-fireblocks-com__cosigner-flow.png`

## 사용 시 주의

- LLM이 markdown + inline image를 한 번에 다 못 읽는 경우가 많다. 본문(텍스트)을 먼저 읽고, 필요한 이미지만 별도로 호출해서 본다.
- 이미지에서 추출한 사실을 위키에 옮길 때도 출처를 남긴다: `(source: <image-filename>)`.
