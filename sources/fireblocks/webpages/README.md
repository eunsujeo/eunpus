# sources/fireblocks/webpages/

웹 클립(블로그·docs HTML) 저장 위치.

## 권장 도구

- [Obsidian Web Clipper](https://obsidian.md/clipper) — 웹 페이지를 마크다운으로 변환

## 파일명 규칙

`YYYY-MM-DD__<host>__<slug>.md`

예시:
- `2026-05-18__docs-fireblocks-com__vault-accounts.md`
- `2026-05-18__blog-fireblocks-com__mpc-cmp-announcement.md`

## 보존할 메타데이터

각 파일 상단에 frontmatter로 출처를 남긴다:

```yaml
---
source_url: https://docs.fireblocks.com/...
clipped_at: 2026-05-18
title: <원본 페이지 제목>
---
```
