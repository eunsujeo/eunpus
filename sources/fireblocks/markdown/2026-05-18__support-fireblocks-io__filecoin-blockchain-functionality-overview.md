# Filecoin Blockchain functionality overview

*Updated 9 days ago* — **PLACEHOLDER**

## One-line summary

Filecoin L1 with EVM-compatible interface. 4 account types (F1/F2/F3/F4); F4 = L1 representation of EVM `0x`. Fireblocks supports EVM interface + 0x↔Fx transfers via FILForwarder.

## Why this matters

EVM/native interop quirks. Standard EVM transfer vs. native Fx transfer 절차가 다름. **Selective full ingest 후보** — Fireblocks의 EVM/native 통합 패턴이 다른 chain에 일반화 가능 시.
