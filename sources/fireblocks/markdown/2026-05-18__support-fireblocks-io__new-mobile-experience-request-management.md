# New mobile experience: Request management

*Updated 2 months ago* (as of 2026-05-18 capture)

<!-- page: 1 -->

## Overview

The new mobile experience provides an efficient interface for managing approval and signing requests in the Fireblocks mobile app. You can quickly review pending requests, switch between different views, and take action with improved visibility and efficiency.

**Minimum version required**: 3.4.0 (Android and iOS)

### Key benefits:

- View all pending requests in a unified list
- Switch between **All**, **Transactions**, and **Administration** views
- See essential information on request cards without opening details
- Filter by workspace to focus on specific tenants
- Dismiss requests you don't need to act on
- Sort requests to prioritize your work
- Apply additional filters to narrow your list

## Workspace selection

Select which workspace to view at the top of the screen. The default is **All Workspaces**, showing requests from all your tenants. Tap the workspace selector to view requests for a specific tenant. Your selection persists as you navigate the app.

<!-- page: 2 -->

## Request views

Select the requests you want to display using the view options at the top of the screen:

- **All (default)**: shows all your requests in a unified list, regardless of type. The total count appears at the top (e.g., "7 requests").
- **Transactions**: shows only transaction signing and approval requests, including transfers, trades, swaps, and other financial operations.

<!-- page: 3 -->

- **Administration**: shows only administrative requests, including user management, policy changes, and workspace configuration.

## Request cards

Each request card displays essential information, including the operation type, workspace, initiator, and timestamp. Additional details like USD value, assets, and risk indicators appear when applicable.

## Sorting requests

Select how to sort your requests from the sort menu:

- **Last initiated (default)**: most recently created at the top.
- **First initiated**: oldest at the top.
- **Highest to lowest USD value**: requests with USD values appear first, followed by transactions without USD values, then administration requests.
- **Lowest to highest USD value**: requests with USD values appear first (lowest amounts on top), followed by

<!-- page: 4 -->

transactions without USD values, then administration requests.

Your sorting preference is saved between sessions.

## Dismissing requests

Remove requests you don't need to act on by swiping left and tapping **Dismiss**.

**Requests you can dismiss**:
- Requests initiated by others (default)
- Most transaction and configuration requests

**Requests you cannot dismiss**:
- Requests you initiated (default)
- MPC operations (add user, key upgrades, re-enrollment)
- Off-exchange policy requests
- DRS finalization requests

## Approving or rejecting requests

To review and act on a request, tap the request card to view full details. Review all information carefully, then tap **Approve** or **Reject**. Complete authentication with your PIN and biometric. Risk-flagged requests require additional confirmation before approval.

## Filtering requests

Access additional filters by tapping the three-dot menu next to the view options.

### Available filters
- **Initiated by me**: show only requests you created
- **Requires my approval**: show requests waiting for your action
- **Signing requests**: show only requests requiring signature

Active filter indicators show which filters are applied and the total number of active filters. Tap **Clear all** to remove all filters and return to the full request list.

<!-- page: 5 -->

## Expired requests

When requests expire, they are automatically removed from your view.

## Settings and navigation

- **Settings**: same functionality as the previous experience
- **QR code scanner**: scan QR codes for various operations
- **Menu**: all previous menu items remain accessible
