# Removing a Ripple (XRP) trust line

*Updated 5 months ago* — **PLACEHOLDER**

## One-line summary

XRP trust line 제거 조건: **reserve balance 0.2 XRP + default flag values**. Fireblocks가 tokenization engine으로 default flag trust line 자동 생성. Wallet balance가 min reserve (1 XRP base + 0.2 XRP/trust line) 미만 시 trust line이 on-chain에서 auto-deleted 가능. XRP는 trust line 무관하게 base 1 XRP 유지 필요.
