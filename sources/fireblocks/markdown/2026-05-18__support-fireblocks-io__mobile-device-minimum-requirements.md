# Mobile device minimum requirements

*Updated 4 months ago* (as of 2026-05-18 capture)

<!-- page: 1 -->

> **Important**
> - Any mobile device that uses the Fireblocks mobile app must have biometric authentication (fingerprint, face, or both) capabilities.
> - The Fireblocks mobile app should continue working on devices running iOS 11.0-14.0, but you won't be able to update the app to later versions.

## Overview

All users who can sign transactions must have a mobile device that meets the minimum requirements listed below with the Fireblocks mobile app installed to sign transactions.

## Minimum requirements

For online workspaces:

- **Android**: A 64-bit device running Android 8.1 or later with authentication capabilities, such as Yubikey, fingerprint, or face authentication. The device must have the Google Play Store application in order to download the Fireblocks app.
- **iOS**: An Apple device running iOS 16.6 or later with authentication capabilities, such as Yubikey, Touch ID, or Face ID. The device must have the Apple App Store application in order to download the Fireblocks app. The device can't be jail broken.

## Cold Wallet device requirements

<!-- page: 2 -->

Cold Wallet workspaces use the Fireblocks Cold Wallet mobile app, which has different minimum requirements.
