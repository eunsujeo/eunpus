# Re-adding a user to the Fireblocks mobile app

*Updated 1 year ago* (as of 2026-05-18 capture)

<!-- page: 1 -->

## Remove the user

Before re-adding the user to the Fireblocks mobile app, you must first remove them and their associated keys:

1. In your Fireblocks mobile app, select the vertical ellipsis (three dots) (for Android) or the menu icon (for iOS) at the top-right area, and then select **Linked users**.
2. Find the user in the correct workspace and then select the ellipsis (three dots) to the right of the user record and select **Remove user** (for Android), or swipe right on the user record and select **Delete** (for iOS) to remove the registered user account (and its corresponding keys), confirming the action when prompted. If you are unable to find the record from the list of linked users, proceed to the next section below.

## Re-add the user

After removing the user from the mobile app, you can re-add them.

1. Log into your Fireblocks Console, and select the relevant workspace.
2. Initiate the mobile app registration sequence again.
