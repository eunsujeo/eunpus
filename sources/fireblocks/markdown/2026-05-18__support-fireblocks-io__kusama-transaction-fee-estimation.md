# Kusama transaction fee estimation

*Updated 1 year ago* — **PLACEHOLDER**

## One-line summary

Kusama 수수료 = fee-per-byte × network fee + optional tip. Console은 tip만 표시. **API "Estimate required fee"는 network fee만 반환** — client가 tip 더해 총합 전송 필요.

## Why this matters

API integration 시 fee 계산 책임이 client 측. Substrate-style fee 모델.
