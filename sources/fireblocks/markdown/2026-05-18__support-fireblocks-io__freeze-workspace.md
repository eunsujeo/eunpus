# Freeze Workspace

*Updated 18 days ago* (as of 2026-05-18 capture)

<!-- page: 1 -->

Freeze Workspace blocks all activity in your workspace during emergencies, such as a security breach. **Any Admin-level user (Owner, Admin, Non-Signing Admin, or Security Admin) can freeze the workspace, but only the Owner can request to unfreeze it.**

**Freezing the workspace changes everyone's user role to Viewer, including the Owner's**, blocking all users from performing any workspace activity. **The workspace still receives incoming transfers while frozen.**

Freeze the workspace only when it faces imminent risk.

## How to freeze a workspace

To freeze a workspace, go to **Settings > General > Freeze workspace** and select **Freeze workspace**.

## How to unfreeze a workspace

To unfreeze a workspace, the workspace Owner must submit a request to Fireblocks Support.
