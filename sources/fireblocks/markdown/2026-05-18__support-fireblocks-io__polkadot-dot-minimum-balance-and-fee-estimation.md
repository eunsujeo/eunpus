# Polkadot (DOT) minimum balance and fee estimation

*Updated 4 months ago* — **PLACEHOLDER**

## One-line summary

Polkadot: **계정 활성화 첫 입금 ≥ 0.01 DOT**. 0.01 미만 시 account reaped + **replay attack 취약**. Fireblocks가 wallet의 0.01 DOT 미만 하강을 방지. Testnet WND도 동일. DOT tx valid period: 2시간 (수동 approver window).

## Why this matters

Reaped account의 replay attack 위험 + 2시간 valid window가 multi-approver 흐름에 시간 제약.
