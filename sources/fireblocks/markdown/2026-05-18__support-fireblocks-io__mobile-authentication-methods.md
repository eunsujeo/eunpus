# Mobile authentication methods

*Updated 3 years ago* (as of 2026-05-18 capture)

<!-- page: 1 -->

The Fireblocks mobile application is required to sign and authorize transactions and to approve external connections.

Depending on their role, users can whitelist addresses, approve authentication requests, and sign transactions using the Fireblocks mobile application on a compatible iOS or Android device.

Users are required to sign and approve notifications using their device's configured authentication method.

## Built-in authentication

Users may configure the Fireblocks mobile application to use the device's built-in fingerprint scanner or facial recognition.

## External authentication

Users may configure the Fireblocks mobile application to use Yubikey for authentication as an alternative to the device's built-in authentication.
