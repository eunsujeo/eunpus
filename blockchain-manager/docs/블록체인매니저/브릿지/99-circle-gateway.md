[3장](03-usdc-gateway.md)의 USDC Gateway 는 Fireblocks 가 **Circle Gateway** 를 감싼 것이다. 이 문서는 Circle 쪽 설명만 모은다. 우리가 직접 붙이는 경우([2장](02-options.md)의 후보)와 비교할 때의 재료다.

출처는 [Circle Gateway 개요](https://developers.circle.com/gateway) 한 건이고, 아래는 그 문서에 있는 내용만이다.

## 무엇인가

여러 블록체인에 걸친 **단일 USDC 잔액**을 만든다. 지원하는 소스 체인의 **비수탁 Gateway Wallet 컨트랙트**에 USDC 를 입금해 두고, API 한 번으로 목적지 체인에서 **USDC 를 즉시 mint** 한다.

우리가 넣은 코인이 체인을 건너가는 것이 아니다. 소스 체인 컨트랙트에 예치가 남고 목적지 체인에서 새로 mint 된다.

## 성질 넷

| | 내용 |
|---|---|
| 단일 크로스체인 잔액 | 여러 체인에 USDC 를 두고 지원 목적지 체인에서 하나의 잔액처럼 쓴다 |
| 즉시 전송 | 잔액이 확립된 뒤 **500ms 미만**. 소스 체인 파이널리티를 기다리지 않는다 |
| 비수탁 | 예치한 USDC 의 소유권을 유지한다. 서명 기반 권한이고 **7일 무신뢰 인출** 경로가 있다 |
| ERC-1271 계약 서명 | 스마트 컨트랙트·스마트 컨트랙트 지갑에서 별도 EOA 대리인 없이 전송을 승인할 수 있다 |

**permissionless 다** — 가입 없이 바로 붙일 수 있다고 문서가 밝힌다. Fireblocks 경유는 Beta·Labs 관문이 있는데, Circle 자체에는 그 관문이 없다.

Gateway 이벤트에 대한 **웹훅**이 있다. 등록한 지갑 주소에 대해 실시간 통지를 받는다.

## CCTP 와의 차이

Circle 문서의 비교표다.

| | CCTP | Gateway |
|---|---|---|
| 용도 | 한 체인에서 다른 체인으로 USDC 전송 | 여러 체인에서 쓸 수 있는 단일 USDC 잔액 보유 |
| 속도 | Fast 8~20초 · Standard 15~19분(Ethereum·L2) | 잔액 확립 후 **500ms 미만** |
| 잔액 모델 | 지점 간 전송 | 크로스체인 단일 잔액 |
| 수탁 | 비수탁 | 비수탁 + **7일 무신뢰 인출** |

용도가 다르다. **한 번 옮기는 것**이면 CCTP, **여러 체인에서 꺼내 쓸 잔액을 두는 것**이면 Gateway 다.

## 우리 문서와 맞춰 볼 것

- **"자금이 Circle 컨트랙트에 있다"** 는 3장의 서술은 맞지만, Circle 은 그 컨트랙트를 **비수탁**으로 규정하고 7일 무신뢰 인출 경로를 둔다. 수탁 판단에서 두 사실을 함께 봐야 한다.
- **소요 시간** — Circle 쪽 전송은 500ms 미만이다. 3장에서 소요 시간을 미확인으로 둔 것은 Fireblocks 를 통했을 때의 전체 시간이고, 그쪽은 입금 확정 정책과 목적지 전달 확인이 지배한다.
- **직접 붙이는 경우** — permissionless 라 Fireblocks 없이도 가능하다. 다만 그때는 서명·키 관리가 우리 몫이 되고 Fireblocks 의 정책·기록 경계 밖으로 나간다. 2장의 후보로 남는다.

## 아직 안 본 것

이 문서는 개요 한 장이다. 아래는 Circle 문서의 다른 페이지에 있어 확인하지 않았다.

- 지원 체인 목록과 체인별 요구 컨펌 수
- 수수료 상세
- 7일 무신뢰 인출의 실제 절차
- Unified Balance Kit 의 내용
- 웹훅 이벤트 종류
