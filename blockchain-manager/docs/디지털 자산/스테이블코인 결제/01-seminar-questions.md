# 람다256 세션에서 확인할 질문

"스테이블코인 PoC 사례로 보는 결제 월렛 보안" (람다256, 여신금융협회·9개 카드사 협력) 세션용 질문 목록이다. 각 질문은 [국내 PoC 구조](00-korea-poc.md)의 "공개 자료에 없는 것" 절과 wiki open question (STBL07·STBL08) 에서 나왔고, 답을 얻으면 그쪽을 갱신한다.

**Q1. SCOPE 의 월렛 커스터디·키 관리 구조는 무엇인가 — MPC 인가 수탁인가?**
두 PoC 발표 모두에 없다. 세션 제목이 "결제 월렛 보안"이라 이번에 확인할 가능성이 가장 높은 항목이다 (STBL07).

**Q2. 취소·환불은 온체인에서 어떻게 표현하나?**
역방향 전송인지, 발행 주체의 소각·재발행인지 미공개다.

**Q3. 온체인 AML·FDS (CLAIR) 는 결제 흐름의 어느 지점에서 실행되나?**
승인 전 차단인지 사후 모니터링인지에 따라 우리 컴플라이언스 게이트 배치와의 비교 지점이 달라진다.

**Q4. 오프램프 PoC 의 단계별 역할 귀속은?**
FX 적용 → 정산 요청 → AML·FDS → 지급 승인 → 온체인 정산 → 원화 지급의 각 단계를 케이뱅크·케이에스넷·람다256 중 누가 수행하는지, 발표는 역할과 흐름을 따로 서술해 단계별 귀속이 비어 있다.

**Q5. 카드사별 전용 시스템과 표준 플랫폼의 경계는?**
표준 플랫폼 외에 카드사별 정책·프로세스를 반영한 전용 시스템 구축 가능성을 확인했다고 발표했다. 무엇이 표준이고 무엇이 카드사별 커스텀인지 확인한다.
