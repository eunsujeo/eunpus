# 발표 자료 이후 남은 확인 질문

한컴위드 발표 자료에서도 확인되지 않은 적용 조건만 남긴다. 발표에서 확인된 `X25519 + ML-KEM-768` 하이브리드 통신, 체인·서비스 계층의 전환 경계와 단계별 준비 순서는 [디지털 월렛의 PQC 전환 범위와 실행 순서](03-wallet-pqc-seminar.md)에 반영했다.

**Q1. KCMVP 검증을 아직 받지 않은 PQC 모듈의 검증 취득 계획·일정은?**
현재는 KCMVP 암호 모듈에 비검증 PQC 모듈을 추가 개발하는 단계다 ([월렛 PQC 전환](01-wallet-pqc-transition.md)). 금융권 도입 요건과 직결된다.

**Q2. 국내 금융권 도입에서 요구하는 월렛·커스터디의 완료 기준은 무엇인가?**
발표 자료는 통신·저장·백업·인증의 전환 순서를 제시하지만, 국내 금융회사가 어느 범위까지 마쳐야 전환 완료로 인정되는지는 다루지 않는다.

**Q3. 서명 키의 하이브리드 (전통+PQC 병행) 적용 사례를 보고 있나?**
Fireblocks 의 하이브리드 채택 여부·key backup 평면은 공개 자료에 없어 wiki open question 으로 추적 중이다 ([월렛 PQC 전환](01-wallet-pqc-transition.md) 확인할 항목 절). 업계 일반의 흐름을 세미나에서 들을 수 있으면 참고로 기록한다.
