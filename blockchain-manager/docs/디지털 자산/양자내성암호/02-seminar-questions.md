# 한컴위드 세션에서 확인할 질문

"디지털 월렛의 양자내성암호 전환" (한컴위드) 세션용 질문 목록이다. 각 질문은 이 카테고리 문서에서 공개 자료로 확인하지 못한 항목에서 나왔고, 답을 얻으면 해당 문서와 wiki open question (Q-2026-08-20-01) 을 갱신한다.

**Q1. xFWeb 의 계층형 하이브리드가 쓰는 PQC 알고리즘은 무엇인가?**
기존 TLS 위에 애플리케이션 계층 PQC 통신을 얹는 구조까지는 공개 기사에 있으나, ML-KEM·ML-DSA 같은 구체 알고리즘 선택은 확인하지 못했다 ([월렛 PQC 전환](01-wallet-pqc-transition.md) 한컴위드 절).

**Q2. KCMVP 검증을 아직 받지 않은 PQC 모듈의 검증 취득 계획·일정은?**
현재는 KCMVP 암호 모듈에 비검증 PQC 모듈을 추가 개발하는 단계다 ([월렛 PQC 전환](01-wallet-pqc-transition.md)). 금융권 도입 요건과 직결된다.

**Q3. 체인 네이티브 서명 평면에 대한 접근이 있나, 통신·저장 평면까지인가?**
월렛의 PQC 전환은 체인 네이티브 서명을 사업자가 못 바꾼다는 경계에서 갈린다 ([월렛 PQC 전환](01-wallet-pqc-transition.md) 도입부). 한컴위드의 "디지털 월렛" 전환 범위가 어느 평면까지인지 확인한다.

**Q4. 2035 국내 전환 일정에서 금융권 월렛·커스터디의 우선 전환 대상은?**
범국가 종합 추진계획은 2035 전체 IT 인프라 전환이 목표다 ([개념](00-overview.md) 국내 정책 일정). 월렛·커스터디 실무에서 무엇부터인지 (통신·저장·백업·인증) 확인한다.

**Q5. 서명 키의 하이브리드 (전통+PQC 병행) 적용 사례를 보고 있나?**
Fireblocks 의 하이브리드 채택 여부·key backup 평면은 공개 자료에 없어 wiki open question 으로 추적 중이다 ([월렛 PQC 전환](01-wallet-pqc-transition.md) 확인할 항목 절). 업계 일반의 흐름을 세미나에서 들을 수 있으면 참고로 기록한다.
