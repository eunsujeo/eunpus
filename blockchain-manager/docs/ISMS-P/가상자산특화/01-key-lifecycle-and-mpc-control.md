가상자산 서명키와 MPC key share의 생성부터 사용·복구·교체·폐기까지 기밀성, 무결성, 가용성과 단독 오·남용 방지를 관리한다.

## 키 목록과 소유권

키·키 세트·Vault별 식별자, 목적·체인·환경, 수탁 대상, 생성 방식, 보관·처리 주체, 정책, 백업·복구, 활성 상태와 책임자를 관리한다. 실제 키·seed·key share는 목록과 증적에 기록하지 않는다.

## 생성·분산

- 승인된 환경·소프트웨어·장치와 참여자만 사용한다.
- 생성 전 목적·수량·정책·참여 주체를 승인한다.
- 단일 지점에 전체 키나 복구 가능한 조합이 노출되지 않도록 설계한다.
- 생성 결과, 공개 식별자, 참여자·시각·무결성과 실패·재시도를 기록한다.
- 시험과 운영 키를 분리하고 생성 후 불필요한 임시자료를 검증·폐기한다.

## 사용과 서명

Co-signer는 승인된 거래 의도와 원본 거래를 대조하고 불일치·만료·재사용·검증 실패 시 거절한다. 키 접근과 서명 참여는 최소권한, 강화된 인증, 네트워크 제한과 감사로그를 적용한다. 키 관리자가 출금 정책 완화와 거래 실행을 단독으로 수행할 수 없게 한다.

## 백업·복구·교체

복구자료는 분리된 위치와 역할로 보호하고 복구 정족수·신원확인·물리·논리 접근을 정한다. 복구시험은 운영키를 노출하거나 무단 자산 이동을 만들지 않는 방식으로 수행한다. 유출·퇴사·벤더 변경·암호기술 전환·장애 시 교체와 자산 이전 절차를 둔다.

## 정지·폐기

키 손상·유출 의심 시 관련 Vault·정책·API 자격·출금을 즉시 제한한다. 잔여 자산과 주소 의존성을 확인한 뒤 복구 불가능한 방법으로 키·복구자료를 폐기하고 공급자 측 복제본·백업의 처리도 확인한다.

## 증적

키 목록, 생성·분산·정책 승인, 접근·서명 로그, 복구·교체 시험, 사고·정지·폐기와 정기 권한·구성 검토 기록을 보관한다.
