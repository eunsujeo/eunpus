관리체계 운영에 참여하는 의사결정자, 실무조직과 시스템 소유자의 책임을 정한다. 실제 조직명과 담당자는 인사발령·직무기술서와 일치시킨다.

## 필수 역할

| 역할 | 주요 책임 | 독립성·분리 기준 |
|---|---|---|
| 최고경영자 | 정책·범위·자원·위험수용과 개선 결과 승인 | 중대 위험의 최종 책임 |
| CISO | 정보보호 관리체계, 위험평가, 사고와 내부점검 총괄 | 서비스 일정만으로 통제를 해제하지 않음 |
| CPO | 개인정보 처리 적법성, 권리보장, 유출 대응 총괄 | 개인정보 목적 외 이용을 독립 검토 |
| 보호위원회 | 중요 정책·위험·사고·예외·투자 심의 | 개발·운영·준법·인사 등 참여 |
| ISMS-P PM | 통제항목, 문서·증적, 일정과 심사 대응 관리 | 통제 소유자의 책임을 대신하지 않음 |
| 시스템·데이터 소유자 | 권한, 변경, 보존, 점검과 시정조치 | 승인과 실행 분리 |
| 키·지갑 책임자 | 키 생명주기, 서명·출금 정책, 대사와 비상조치 | 키 관리와 자산 이전 단독 수행 금지 |
| 내부감사자 | 정책·법규·실제 운영의 독립 점검 | 구축·운영 담당자와 분리 |

## 협의체 운영

보호위원회는 정기적으로 다음을 검토한다.

- 관리체계 운영지표와 미수행 항목
- 고위험 미비점과 시정조치 지연
- 관리자 권한, 정책·키 변경과 고액·이상 거래
- 개인정보 처리·위탁·국외이전 변경
- 사고·장애·취약점과 반복 원인
- 외부자 보안수준과 서비스 연속성

회의자료, 참석자, 의사결정, 책임자와 완료일을 기록한다.

## 직무분리 최소 기준

- 소스 작성자와 운영 배포 승인자
- 권한 요청자·승인자·부여자·정기 검토자
- 출금 요청·정책 승인·서명 승인·대사 담당자
- 키 생성·복구 작업자와 승인·감사 담당자
- 개인정보 추출 요청자와 승인·반출 담당자
- 내부감사자와 점검대상 통제 운영자

인원 부족으로 분리가 어려우면 다중 승인, 불변 감사로그, 사후 독립 검토, 금액·시간 제한과 자동 경보를 적용하고 위험을 승인받는다.

## 담당자 변경

인사발령, 휴직·퇴직 또는 외주 변경 시 책임 인계, 계정·권한 회수, 문서·미결 이슈·비상연락망 갱신을 완료한다. 임시 대행자는 기간과 권한 범위를 승인받는다.

## 증적

- CISO·CPO 지정 문서와 직무기술서
- 조직도, 위원회·협의체 운영 규정과 회의록
- 통제항목별 RACI와 담당자 명단
- 직무분리 분석과 보완대책 승인
- 담당자 변경·인수인계 기록
