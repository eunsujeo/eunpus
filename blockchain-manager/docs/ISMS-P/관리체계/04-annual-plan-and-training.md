선정한 보호대책을 일정, 담당자와 예산에 연결하고 반복 업무·교육의 수행 상태를 관리한다.

## 연간계획 구성

| 영역 | 포함할 활동 |
|---|---|
| 거버넌스 | 경영진 보고, 정책·범위·법규 검토, 위험평가 |
| 인력 | 전사 교육, 역할별 교육, 입·퇴사와 주요 직무자 검토 |
| 접근 | 관리자·DB·클라우드·벤더 권한 검토와 휴면·공유계정 점검 |
| 기술 | 취약점·패치, 구성 점검, 로그 검토와 보안시험 |
| 개인정보 | 처리현황, 위탁·국외이전, 권리요청, 보유·파기 점검 |
| 지갑 | 키·서명 정책, 출금, 대사, 비상정지와 복구훈련 |
| 감사 | 내부감사, 시정조치와 경영진 검토 |

각 활동에 기준 ID, 책임자·검토자, 주기, 목표일, 예산, 산출 증적과 완료 조건을 지정한다.

## 교육 체계

- 전 임직원: 정책, 개인정보, 피싱, 사고신고와 금지행위
- 개인정보취급자: 최소처리, 안전한 조회·추출·제공·파기와 권리요청
- 개발자: 위협모델, 안전한 코딩, 비밀값·로그·시험데이터와 변경관리
- 운영자: 특수권한, 출금·키·정책 변경, 장애·사고·복구와 증적
- 경영진: 주요 위험, 법적 책임, 자원·위험수용과 사고 의사결정
- 외부자: 허용된 접근, 비밀유지, 사고보고, 계약 종료와 자료 반환

교육 후 단순 참석 여부뿐 아니라 평가, 모의훈련 또는 업무 점검으로 효과성을 확인한다.

## 이행관리

미수행·지연은 숨기지 않고 사유, 위험, 임시 대책과 새 완료일을 기록한다. 반복 지연이나 중대 위험은 보호위원회에 보고한다. 자동화된 업무도 실행 성공률, 누락과 실패 처리 결과를 사람이 정기적으로 검토한다.

## 증적

- 승인된 연간계획과 예산
- 월·분기 이행 현황, 지연·예외와 개선 기록
- 교육자료, 참석·평가·미이수 후속조치
- 운영지표와 경영진 보고자료
