Fireblocks, 클라우드, 트래블룰, AML·KYT와 유지보수 사업자를 선정·계약·감독·종료하는 기준을 정한다.

## 외부자 목록

서비스, 계약 소유자, 처리 데이터, 개인정보 위탁·제3자 제공·국외이전 구분, 운영국가, 접근권한, 하위 수탁자, 장애 영향, 계약·종료일과 최근 점검일을 관리한다.

## 계약 전 평가

- 회사·서비스와 재무·운영 지속성
- 보안·개인정보 인증과 독립 감사자료의 범위·유효성
- 관리자 접근, 암호화, 로그, 취약점·사고 대응과 통지
- 데이터 위치, 하위 수탁자, 반환·삭제와 감독권
- 가용성, 백업·복구, 종료·전환과 데이터·키 이전 가능성
- 지갑 사업에서는 키 조각, 정책·서명 권한과 책임 분담

평가에서 확인되지 않은 사항은 `기능 없음`으로 단정하지 않고 계약 조건 또는 미비점으로 기록한다.

## 계약 필수사항

목적·범위, 비밀유지, 최소 권한, 보안 요구사항, 개인정보 처리 조건, 사고·유출 통지, 로그·증적 제공, 점검권, 하위 수탁자, 보존·삭제, 계약 종료와 책임·배상을 명시한다. 서비스 약관과 부속 합의서가 충돌하는지 법무가 검토한다.

## 운영 감독

중요도에 따라 정기 점검, 인증·감사보고서 검토, SLA·사고·취약점과 권한 확인을 수행한다. 대시보드 정상 상태만으로 보호대책 전체를 확인했다고 보지 않는다. 미비점은 책임자와 기한을 정하고 완료를 재검증한다.

## 변경·종료

계약·서비스·데이터 위치·하위 수탁자 변경을 사전에 평가한다. 종료 시 계정·API 자격·네트워크 접근을 회수하고 데이터·백업·키 자료의 반환·이전·삭제를 확인한다. 대체 공급자 또는 자체 운영 전환 가능성을 시험한다.

## 증적

외부자 목록, 사전평가, 계약 보안조항, 정기점검·SLA 보고, 사고·미비점 조치와 종료 확인서를 보관한다.
