시스템 가용성, 장애, 로그, 시간과 보안 모니터링을 운영한다. 세부 로그 필드와 금지정보는 [기존 운영 로그 정책](../../BC/설계/11-operational-log-policy.md)을 참조해 확정한다.

## 운영 기준

서비스별 용량·성능·가용성 지표, 경보 임계값, 담당자, 대응시간과 에스컬레이션을 정한다. 장애는 탐지, 기록, 영향평가, 복구, 대사, 원인분석과 재발방지까지 추적한다.

## 필수 로그

- 인증 성공·실패, 계정·권한 생성·변경·회수
- 관리자·특수권한과 긴급접근 사용
- 배포·설정·보안정책·키 생명주기 변경
- 출금 요청·승인·거절·서명·전파·대사 상태
- 개인정보 조회·추출·제공·파기와 권리요청
- 보안장비, 네트워크, DB와 외부자 연계 사건
- 로그 수집 실패, 시간오차와 삭제·보존 정책 변경

로그에는 비밀번호, 토큰, API key, 개인키·seed·키 조각, 인증 header와 불필요한 개인정보를 기록하지 않는다.

## 보호와 검토

로그를 중앙 수집하고 전송·저장 암호화, 최소권한, 위·변조·삭제 탐지, 백업과 용량경보를 적용한다. 시스템 시각을 표준시각에 동기화하고 오차를 감시한다. 위험 기반 주기로 로그를 검토하고 이상행위의 조사·조치·종결을 기록한다.

## 단말·보안시스템

업무용 단말은 등록·암호화·화면잠금·패치·악성코드 방지·원격접근 정책을 적용한다. 보안시스템은 관리자, 정책·룰 변경, 업데이트, 경보검토와 장애 시 대체절차를 정한다.

## 증적

운영지표·장애 기록, 로그 목록·보존정책, 수집·시간동기화 상태, 정기 로그검토, 경보·이상행위 조치와 단말·보안시스템 점검 결과를 보관한다.
