현재 일반 ISMS-P 인증기준 101개 항목을 문서와 운영 증적에 연결하는 정본이다. 모든 항목의 초기 상태는 `확인 필요`이며 인증범위와 실제 운영을 조사한 뒤에만 변경한다.

## 작성 규칙

- `적용`은 적용·일부 적용·해당 없음 중 하나로 확정하고 근거를 남긴다.
- `책임`에는 개인 이름 대신 승인된 역할을 쓰고 별도 담당자 명단과 연결한다.
- `문서`는 요구사항을 규정하는 정본, `증적`은 실제 이행 기록의 ID를 쓴다.
- 하나의 문서나 증적이 여러 항목을 지원할 수 있으나 항목별 확인 내용을 구분한다.
- `해당 없음`은 시스템이 없다는 말만 쓰지 않고 업무·데이터·연계 분석과 승인 근거를 남긴다.
