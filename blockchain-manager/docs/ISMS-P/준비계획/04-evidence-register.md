심사에서 제시할 운영 기록을 통제항목, 책임자와 보관 위치에 연결한다. 이 문서는 증적 원본이 아니라 민감정보를 제외한 색인이다.

## 증적 목록 필드

| 필드 | 작성 기준 |
|---|---|
| 증적 ID | 영역별 고정 접두어와 일련번호 사용 |
| 통제항목 | 연결되는 ISMS-P 기준 ID |
| 증적명 | 수행 사실을 알 수 있는 이름 |
| 생성 주체 | 자동 시스템 또는 담당 역할 |
| 검토자 | 생성자와 구분된 검토자 |
| 생성 주기 | 상시·월·분기·반기·연·사건 발생 시 |
| 대상 기간 | 기록이 증명하는 시작일과 종료일 |
| 보관 위치 | 접근 통제 저장소의 논리 경로·문서 ID |
| 보존 기간 | 법무·보안이 승인한 기간과 근거 |
| 민감도 | 공개·내부·기밀·개인정보 등 회사 분류 |
| 상태 | 예정·수집·검토·보완·확정 |

## 원본 보관 금지선

Git에는 고객·임직원 개인정보, 전체 권한 목록, 취약점 세부정보, 운영 로그 원문, 비밀값과 키 자료를 넣지 않는다. 심사용 추출본을 만들 때도 필요한 표본만 선택하고 불필요한 식별자는 마스킹한다. 마스킹 전 원본과 추출본의 접근·다운로드 기록을 남긴다.

## 품질 점검

- 정책에 정한 주기와 실제 증적 생성 주기가 같은가.
- 기간 전체를 보여 주는가, 심사 직전에 만든 한 장의 화면인가.
- 생성자, 검토자, 승인자와 조치 완료가 확인되는가.
- 실패·예외·미수행 기록도 숨기지 않고 시정조치와 연결되는가.
- 증적 시각, 시스템명과 문서 버전이 서로 일치하는가.
