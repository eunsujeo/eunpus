국내 도입이 확정이라, 1장(Notabene 연동)에 대응하는 국내 솔루션 연동 준비를 정리한다. 국내 도달은 VerifyVASP 직접 연동(6장 경로 B)이 기준이고, CODE 회원은 상호연동 경유라 별도 준비가 없다(상호연동 실효가 부족할 때만 CODE 직접 준비 — 아래).
1장 Notabene 이 코드 0줄·SaaS 연결이었다면, 이쪽은 **자체 인프라에 설치물을 두고 운영**하는 것이 핵심 차이다.

## 준비 순서

1. **회원 가입·가격 확정** — 아래 "확인 필요"의 미확정 해소가 선행.
2. **상대 승인·실사 정책 확정** — 도달 가능한 회원 목록과 실제 거래 승인 목록을 분리하고 실사 책임·재실사 주기를 정한다.
3. **Enclave 설치** — 아래 요건 표.
4. **수신 콜백 구현** — Enclave 가 호출하는 VASP API 를 컴플라이언스 게이트 엔드포인트로(아래).
5. **VerifyVASP 어댑터 연결** — 컴플라이언스 게이트 안(8장).
6. **테스트** — RobotVASP E2E·입출금 시나리오 테스트(공식 문서에 테스트 절차 제공).

## 준비 대상 — 둘

- **설치형 Enclave 서버** — VerifyVASP 가 강제하는 별도 배포물. 암호화 키·PII 를 우리 인프라에서 보관·처리한다(6·12장).
- **수신 콜백 엔드포인트** — Enclave 가 호출하는 VASP API 를 컴플라이언스 게이트가 구현한다. 별도 배포 없음(8장).

Notabene 은 이 둘이 없다 — SaaS 라 자체 설치물이 없고 인바운드도 벤더가 처리한다.

## 회의에서 전달받은 운영·네트워크 조건

아래는 2026-08-12에 전달받은 [담당자 회의록](https://github.com/eunsujeo/eunpus/blob/main/blockchain-manager/sources/travel-rule-solutions/verifyvasp-meeting/2026-08-12__meeting-notes.md)의 설명이다. 공개 개발자 문서의 확정 요건과 구분하며 계약·운영정책으로 확인한다.

| 항목 | 회의 설명 | 도입 시 처리 |
|---|---|---|
| 상대 VASP 실사 | Wolfsberg CBDDQ 준용, 위험도에 따라 3·6·12개월 재실사 | 자료 전달 주체와 별개로 승인 판단·증적·재실사 스케줄은 우리 책임으로 설계 |
| 국내 접점 | AWS 한국 리전 | 실제 endpoint와 데이터 레지던시를 계약으로 확인 |
| 해외 거래 | 싱가포르 경유 | 대상 데이터·보관 여부·장애조치 경로 확인 |
| 암호화 | 거래 건별 키페어, 수신측 인프라에서 복호화 | `PerVerification` 필수 여부와 키 회전·복구 절차 확인 |
| 중앙 저장 | 메모리 처리 후 폐기 | 중앙 무저장과 우리 Enclave DB 저장을 분리해 보안성 검토 |

망분리 경계의 고정 문자열·고정 길이 전문과 JSON 불허는 회의에서 논의된 **당행 내부 설계안**이다. VerifyVASP Enclave API가 JSON을 사용하지 않는다는 뜻이 아니다. 필요하면 업무망↔DMZ 사이에 제한된 고정 전문을 두고, DMZ 내부 어댑터가 Enclave API 계약으로 변환하는 별도 설계를 검토한다.

## 수신 콜백 — 컴플라이언스 게이트의 엔드포인트

- Enclave 가 호출하는 **VASP API 구현** — Verify User · User Account Verification · Callback · Check Transaction Status.
- 콜백은 **얇게** 둔다 — 검증·변환 후 서비스 내부 처리로 넘긴다. 사전 검증 기록·1차 대조는 컴플라이언스 게이트, 귀속 판단·가용 전이는 DAW-CORE다(8장 경계).
- 별도 배포 이유 — 기관 간 콜백 트래픽의 인바운드 접점을 얇게 분리(장애 격리·배포 주기).

## 우리가 새로 지는 것

- **키·PII 보관처가 우리 쪽에 생긴다** — Notabene(벤더 보관)과 달리 평문 PII·키가 우리 Enclave 안에 있다. 보안·감사 책임이 따라온다(12장 자격증명 격리와 같은 선).
- **운영 부담** — Enclave 설치·HA·모니터링. Fireblocks 스크리닝용 전용 API user 자격증명과도 별개다(12장).

| | Notabene (해외 · 1장) | VerifyVASP (국내 · 이 장) |
|---|---|---|
| 성격 | SaaS 연결 | 자체 인프라 설치·운영 |

## CODE 는?

기본은 VerifyVASP↔CODE 상호연동 경유라 **별도 준비 없음**이다(빗썸·코인원·코빗에 VerifyVASP 로 도달). 단 상호연동 실효(원화 임계·TXID 역추적 등)가 부족하면 **CODE 직접 준비**가 필요하다 — CODE-Cipher(설치형 암호화 모듈) 설치. 조건부 판단은 6장 비교표·11장 부록 A.

## 확인 필요 — 미확정(6장)

- **VerifyVASP 가격·회원 가입 조건**.
- **Enclave HA·스케일링·권장 사양** — 공식 문서에 없음.
- **운영 대행(managed) 옵션 존재 여부** — 없으면 자체 운영이 필수(PII 를 회원 인프라에만 두는 솔루션 구조상 대행이 어려울 수 있음).
- **VerifyVASP↔CODE 상호연동 실효** — CODE 직접 준비 여부를 가른다.
- **VerifyVASP↔CODE 양 방향의 동의·실사·정보 제공 권한** — 기술 연결과 거래 승인을 분리해 확인한다.
- **한국 리전·싱가포르 경유 범위** — endpoint, 데이터 레지던시, 보관 위치, 장애조치 경로를 계약으로 확정한다.
- **건별 키페어 설정** — `PerVerification`이 필수인지 선택인지와 키 복구·회전 절차를 확인한다.
