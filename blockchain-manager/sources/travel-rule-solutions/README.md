# 트래블룰 솔루션 원본 자료

`docs/BC/트래블룰솔루션/` 카드에서 인용하는 공식 원문 스냅샷이다. 조사 결과와 원본을 분리해, 웹 문서가 바뀌어도 당시 판단 근거를 다시 확인할 수 있게 한다.

## 보존 규칙

- 이 폴더의 날짜가 붙은 원본은 수정하지 않는다. 변경된 문서는 새 수집일 파일로 추가한다.
- 각 솔루션의 `manifest.yml`에 원본 URL, 수집일, 발행 주체, 자료 등급, SHA-256을 기록한다.
- 문서 카드는 공식 URL을 링크하고, 같은 행에 로컬 스냅샷 경로와 Source ID를 기록한다.
- 공식 문서의 제품 설명도 `벤더 공식 문서에서 확인`한 사실이다. 실제 도달성·성능·운영 결과를 증명하지는 않는다.
- 공식 문서에 없는 가격, SLA, 회원별 연결 상태, 지원 약속은 추정하지 않는다.

## 자료 등급

| 등급 | 의미 |
|---|---|
| A1 | 법령·정부·규제기관 원문 또는 표준 제정·관리 주체의 공식 표준 원문 |
| A2 | 솔루션 운영사의 공식 API·기술·운영 문서 |
| A3 | 솔루션 운영사의 공식 보안·개인정보·감사 문서 |
| B1 | 당사자 중 한쪽의 공식 파트너십·상호운용 발표 |
| B2 | 공식 제품·마케팅 페이지 — 벤더 주장으로만 사용 |
