# Introduction



Welcome to CodeVASP [#welcome-to-codevasp]

CodeVASP is a travel rule protocol created by South Korea's leading digital
asset exchanges—Bithumb, Coinone, and Korbit. It allows different
cryptocurrency platforms to "talk" to each other.
