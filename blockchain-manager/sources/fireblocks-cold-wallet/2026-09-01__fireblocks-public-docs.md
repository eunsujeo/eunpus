## 확인 범위

- Cold Wallet 전용 workspace와 Hot·Warm workspace를 분리하는 방식
- Air-gapped iOS 기기에서 이뤄지는 양방향 QR 서명
- Owner 기기를 먼저 등록하고 Signer 기기에서 signature pre-processing을 수행하는 절차
- 초기 설정 중에는 인터넷에 연결하고 설정 후에는 네트워크를 차단하는 절차
- Cold Wallet 거래에 적용되는 8시간 서명 timeout
- P2P Network 양측의 Admin Quorum 승인과 Automated Address Authentication
- Mobile key share 백업·복구 문서의 적용 범위 제약

## 사용 제약

이 파일은 발행 문서의 출처 색인이다. 세부 사실을 확인할 때는 정규화 원본과 각 공식 URL을 함께 본다. `Mobile Key Share Backup and Recovery`는 Cold Wallet 전용 문서가 아니므로 Cold Wallet 절차로 일괄 적용하지 않는다.
