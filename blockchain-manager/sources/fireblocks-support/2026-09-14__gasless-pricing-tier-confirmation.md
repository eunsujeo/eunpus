# Fireblocks Universal Gasless 구독료·거래 건수 확인

> 출처: 사용자가 2026-09-14 전달한 Fireblocks 담당자 답변. 실제 회신 일시는 별도로 제공되지 않았다.
> 선행 대화: [2026-09-07 가격 범위 1차 회신](2026-09-07__gasless-pricing-ranges-conversation.md)

## 질문과 답변 (원문)

1. Are these monthly subscription fee tiers only, with the actual gas costs reimbursed separately on top?

> Yes, correct

2. Does the transaction count for each tier include first-time EIP-7702 account upgrade transactions?

> Yes, it's any tx that fireblocks pays the fees for

## 확인된 내용

- 9월 7일 제시한 가격 범위는 월 구독료 티어다. 실제 가스비는 별도로 상환한다.
- 티어 거래 건수에는 최초 EIP-7702 계정 업그레이드 거래도 포함된다. 집계 기준은 Fireblocks가 가스비를 지불한 모든 거래다.
- 이번 답변에는 가격 범위의 변경이나 최종 견적 확정, 최초 업그레이드와 전송이 별도 거래로 처리되는지에 대한 설명은 없다.
