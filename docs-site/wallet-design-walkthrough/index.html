전제 (합의 완료)

Fireblocks 를 분석해 자체 블록체인 매니저를 만든다. 처음에는 자체 매니저로 테스트한 뒤 Fireblocks 로 전환해도 다른 시스템에 영향이 없어야 한다. 체인은 이더리움·Canton 으로 시작한다. 나중에 다른 체인이 붙어도 마찬가지다.

  1. 0읽는 법 + 등장인물 + Fireblocks 해부 매트릭스먼저 읽기
  2. 1계정 생성 — createAccount온보딩
  3. 2입금 주소 발급 — issueDepositAddress온보딩·운영
  4. 3입금 주소 조회 — addressOf고객 화면
  5. 4입금 — 감지에서 확정까지자금 유입
  6. 5수수료 견적 — estimateFee출금 준비
  7. 6출금 — 제출에서 확정까지, 막혔을 때자금 유출
  8. 7잔액과 내역 조회 — getBalance · transactionsOf고객 화면
  9. 8전환과 확장 — 이 4분면이 가능한 이유마무리
