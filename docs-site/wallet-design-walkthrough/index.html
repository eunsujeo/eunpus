전제 (합의 완료)

Fireblocks 를 분석해 자체 블록체인 매니저를 만든다. 처음에는 자체 매니저로 테스트하고, 이후 Fireblocks 로 전환해도 다른 시스템에 영향이 없어야 한다. 체인은 이더리움·Canton 으로 시작하고, 나중에 다른 체인이 붙어도 마찬가지다.

  1. 1Fireblocks 해부 — 기능 인벤토리와 사용처 매트릭스이 문서의 지도
  2. 2한 줄의 가격 — createTransaction 해부해부
  3. 3포트 두 개 — 매트릭스가 인터페이스가 되는 과정경계
  4. 4불변식 — 시그니처가 같아도 의미가 같아야 한다경계
  5. 5계정·주소 — 지갑 생성은 키 생성이 아니다자체 구축
  6. 6출금 — exactly-once 의 진짜 적자체 구축
  7. 7입금 — 커밋이 롤백되는 DB자체 구축
  8. 8신뢰 경계 — 서명자는 장님이면 안 된다자체 구축
  9. 9전환 증명 — 코드·데이터·자금은 다른 경계다이 문서의 심장
  10. 10확장 증명 — N번째 체인은 어댑터 하나다마무리
