전제 (합의 완료)

1차 목표는 두 백엔드가 블록체인 매니저를 부르는 통로(포트) 하나를 EVM(이더리움·Base) 위에 세우는 것이다. 두 백엔드는 물리적으로 분리한다 — Service 백엔드(고객 런타임: 입금·출금·잔액)와 Admin 백엔드(운영·거버넌스: 정책·승인·키·동결·rebalance)가 별도 배포·권한·감사 경계로 나뉜다.

포트로 추상화하므로 매니저를 바꿔도 두 백엔드 코드는 그대로다. EVM 체인이 늘어도(이더리움·Base, 이후 다른 L2) 백엔드는 안 바뀐다 — 체인 분기는 포트 뒤에 갇힌다. 훗날 매니저(벤더)를 교체해도 같은 포트가 그 변화를 흡수한다.
