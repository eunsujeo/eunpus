SPEC 2 · LIBRARY DESIGN

기능 spec

WalletIndexerPort 의 method 들 — Must-have / Should-have / Nice-to-have 분류.

기초안내

Port 는 5 개 영역 의 method 를 가진다:

  1. Wallet management — 입금 주소 등록 / 조회
  2. Deposit detection — 입금 event stream + balance query
  3. Withdrawal — 출금 제출 + 상태 추적
  4. Reconciliation — 회계 마감 / audit 용 fact query
  5. Health · Capability — adapter 상태 + 지원 기능 negotiate
다음 단계 — Must-have 핵심 method

Alice 의 입금 / 잔고 조회 / 출금 의 minimum surface.

interface WalletIndexerPort {
  // 1. Wallet management
  registerWallet(req: RegisterWalletRequest): Promise<WalletDescriptor>;
  getWallet(walletId: WalletId): Promise<WalletDescriptor>;

  // 2. Deposit detection
  subscribeDeposits(handler: (e: DepositEvent) => Promise<void>): Subscription;
  getBalance(walletId: WalletId, asset: Asset): Promise<Balance>;
  getDepositHistory(req: DepositHistoryQuery): Promise<DepositEvent[]>;

  // 3. Withdrawal
  submitWithdrawal(req: WithdrawalRequest): Promise<WithdrawalReceipt>;
  getWithdrawalStatus(withdrawalId: WithdrawalId): Promise<WithdrawalStatus>;

  // 4. Reconciliation
  getBalanceAsOf(walletId: WalletId, asset: Asset,
                 blockNumber: number): Promise<Balance>;
  listEventsInRange(query: EventRangeQuery): Promise<Event[]>;

  // 5. Health · Capability
  capabilities(): AdapterCapabilities;
  health(): Promise<HealthStatus>;
}

각 method 의 design 의도를 보자.

subscribeDeposits — Push 기반

Polling 아닌 stream subscription. Adapter 내부에서 vendor webhook / WebSocket / Kafka 등을 받아 통일된 DepositEvent 로 emit. Handler 는 idempotent 해야 함 (같은 event 가 두 번 올 수 있음 — 명시).

getBalanceAsOf(blockNumber) — 회계 evidence

"마감 시점 (블록 N) 의 잔고는?" 회계 / 감사용. Vendor 가 archive node 미지원하면 capability 에서 false 로 표시. 자체구축 path 만 항상 지원.

핵심 type 정의

type ChainId = 'ethereum' | 'bitcoin' | 'solana' | 'polygon' | string;
type WalletId = string;
type Asset = { chain: ChainId; symbol: string; contractAddress?: string };

interface DepositEvent {
  idempotencyKey: string;
  walletId: WalletId;
  asset: Asset;
  amount: bigint;      // raw smallest unit (wei / satoshi)
  fromAddress?: string;
  txHash: string;
  blockNumber: number;
  blockHash: string;
  observedAt: Date;       // adapter 가 본 시각
  confirmedAt: Date | null;  // null = pending
  confirmationCount: number;
  source: 'webhook' | 'poll' | 'reorg-revert';
}

interface Balance {
  asset: Asset;
  confirmed: bigint;
  pending: bigint;
  asOfBlock: number;
  asOfTime: Date;
}

interface WithdrawalRequest {
  walletId: WalletId;
  destination: string;
  asset: Asset;
  amount: bigint;
  idempotencyKey: string;   // ★ 영구 멱등성
  feeTier?: 'low' | 'medium' | 'high';
  metadata?: Record<string, string>;
}

interface WithdrawalStatus {
  state: 'pending_signing' | 'broadcasting' | 'mempool' |
         'confirming' | 'completed' | 'failed' | 'cancelled';
  txHash?: string;
  blockNumber?: number;
  failureReason?: string;
}

interface AdapterCapabilities {
  vendor: 'fireblocks' | 'bitgo' | 'nodeinfra' | 'own';
  supportsWebhook: boolean;
  supportsBatchWithdrawal: boolean;
  supportsCustomConfirmationPolicy: boolean;
  supportsBalanceAsOf: boolean;
  supportsAddressScreening: boolean;
  supportedChains: ChainId[];
  internalTxDetection: 'trace_api' | 'log_only' | 'none';
  webhookOrdering: 'guaranteed' | 'not_guaranteed';
  reorgHandling: 'automatic' | 'event_only' | 'manual';
}

interface HealthStatus {
  status: 'healthy' | 'degraded' | 'down';
  vendorReachable: boolean;
  ingestionLagSeconds: number;
  lastEventAt: Date;
  message?: string;
}

주의 — Capability negotiation 필수

평면 3 코드는 항상 capability check 후 분기:

const caps = indexerPort.capabilities();
if (caps.supportsBalanceAsOf) {
  const bal = await indexerPort.getBalanceAsOf(walletId, asset, closingBlock);
} else {
  // Fallback: 이벤트 합산
  const bal = await reconstructBalanceFromEvents(walletId, asset, closingBlock);
}
