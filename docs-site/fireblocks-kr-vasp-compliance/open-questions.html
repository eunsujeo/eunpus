7. 별도 검증이 필요한 항목 — 미해결 Open Questions

Fireblocks × KR 컴플라이언스 매핑에서 공식 문서로 명확히 답이 나오지 않은 8 개 항목. 사업자가 도입 결정 전 Fireblocks Sales · 법무법인 · 금감원 등과 직접 확인해야 하는 영역.

7.1 망분리 해석 — Fireblocks SaaS 가 부합하는가

질문

KR 전자금융감독규정의 IT 망분리 요건이 Fireblocks SaaS 사용에 어떻게 적용되는지. 은행 망분리 IDC 와 Fireblocks Azure 인프라 (US / EU / EU2) 간의 통신이 망분리 해석에 부합하는지.

이게 답이 안 나오는 이유

  • 전자금융감독규정의 망분리 조항은 가상자산 사업자 전용이 아닌 일반 전자금융업 규정
  • 가상자산업 적용 해석은 금감원 / 금융위의 비공개 가이드 영역
  • 실명계정 발급 은행의 자체 AML 위험평가에서 평가되는 항목이기도

확인 방법

  • 금감원 또는 금융위에 비공식 의견조회
  • 실명계정 발급 은행의 자체 위험평가 가이드 확인
  • Fireblocks Sales 와 KR 망분리 대응 옵션 협의 (Hosted MPC / Key Link / On-Prem Cosigner 등)

7.2 금융회사 정보처리 업무 위탁 규정의 적용

질문

은행 또는 기존 금융회사가 가상자산 수탁 사업 진출 시, Fireblocks SaaS 사용이 「금융회사의 정보처리 업무 위탁에 관한 규정」 의 외주 위탁 대상에 해당하는지.

왜 중요한가

  • 외주 위탁 대상이면 — 사전 보고 / 위탁 계약 사전심사 / 정기 점검 등 별도 의무 부과
  • 은행이 SaaS 인프라 사용 시 자주 등장하는 해석 문제

확인 방법

  • 법무법인 의견서 (금융법 전문)
  • 금감원 비공식 의견조회
  • 실제 운영 은행의 사례 (현재 공개된 case 부재)

7.3 ISMS 인증 심사에서 Fireblocks SaaS 평가 방법

질문

ISMS / ISMS-P 인증 심사 시 Fireblocks SaaS 가 평가 대상에 어떻게 포함되는지. Fireblocks 의 SOC 2 / ISO 27001 인증서가 ISMS 심사 input 으로 인정되는지.

확인 방법

  • ISMS 인증 기관 (KISA 또는 사설 기관) 사전 협의
  • 최근 ISMS 인증 받은 VASP 의 사례 참고
  • Fireblocks Sales 의 KR ISMS 대응 자료 (현재 공식 자료 부재)

7.4 Cold Wallet MPC share 분포 (Q-M05)

질문

Fireblocks Cold Wallet workspace 의 MPC 3-share 모델이 Hot 의 "1 mobile + 2 Fireblocks Azure SGX" 와 동일한가, 다른가? 별도 Cold device 인가, Fireblocks 측 cold facility 인가?

왜 중요한가

  • 대법원 2024도10710 의 "실질 통제" 판단에서 share 분포가 평가 변수
  • Fireblocks 측 share 비중이 높으면 — 사업자의 자기 통제력에 의문 (사업자가 단독 통제 어려운 vs 사업자가 실질 통제)
  • BCM (Business Continuity Module) 의 Cold 적용 여부 결정

확인 방법

  • Fireblocks Sales 와 직접 협의
  • Cold Wallet 별도 product 계약 시 architecture 명세 요청

7.5 MPC·멀티시그 사업자의 "실질 통제" 임계점 (Q-CMP-08)

질문

대법원 2024도10710 의 ratio — "MPC·멀티시그·공동승인 구조라도 사업자가 자산 이동을 실질적으로 통제하거나 승인권을 행사하면 '보관 또는 관리' 또는 '이전' 행위로 평가될 가능성이 높음" — 의 wallet architecture 적용 임계점.

  • 금융위 비공식 의견조회

7.6 "동종·동량" 의 실무 인터프리테이션 (Q-CMP-06)

질문

이용자보호법 시행령의 "이용자 가상자산과 동종·동량의 가상자산을 실질적으로 보유" 의 검증 시점·허용 buffer. Sweeping 중간 시점·Hot↔Cold rebalancing 중·gas station 이체 직후 등의 잠시 차이가 허용되는지.

확인 방법

  • 금감원·금융위 가이드 (현재 공개 문서 명확 답 없음)
  • 최근 VASP 의 분기 reporting 사례
  • 외부 회계법인 의견

7.7 미신고 해외 VASP 의 "한국인 유치" 판단 기준 (Q-CMP-07)

질문

해외 미신고 VASP 단속 시 "한국어 홈페이지, 원화결제 지원, 한국인 유치 이벤트 등이 영업성 판단요소" — 정확한 cumulative test 인지, 단일 요소 충족 시 영업성 인정인지.

왜 중요한가

  • 한국 사업자가 해외 사업자와 거래할 때, 해외 사업자가 "내국인 대상 영업" 으로 판단되면 미신고 VASP 거래 위반
  • 2022-08-18 16 개 외국 VASP 차단 조치의 판단 기준

확인 방법

  • 금감원 보도자료 (현재 cumulative test 명시 없음)
  • 판례 (현재 직접 답한 판례 부재)
  • 법무법인 의견

7.8 2026 년 개정안의 정식 시행일 (Q-CMP-01)

질문

2026-03-30 예고된 시행령·감독규정 개정안의 정식 시행일. 일부 항목은 2026-08 시행 예정으로 표시되어 있으나, 구체 일자 미공개.

주요 변동 사항

  • 대주주 범위 구체화
  • 신고사항 세분화
  • 고위험 고객에 대한 강화 고객확인 명확화

확인 방법

  • 금융위 보도자료 (정기 모니터링)
  • 국가법령정보센터의 시행령 공포 모니터링

7.10 권장 — 의사결정 전 사전 확인

Fireblocks 도입 결정 전 위 8 개 항목 중 다음 최소한은 사전 확인 권장:

  1. ★★★★★ 망분리 해석 (7.1) — Fireblocks Sales 와 협의 + 실명계정 발급 은행 의견. SaaS vs Hosted MPC 의 선택이 결정됨.
  2. ★★★★★ 실질 통제 임계점 (7.5) — 법무법인 의견서. 사업모델 자체의 VASP 평가가 갈림.
  3. ★★★★ ISMS Fireblocks 평가 (7.3) — ISMS 인증 기관 사전 협의. 6–12 개월 critical path 의 시작.
  4. ★★★★ 2026 개정 (7.8) — 도입 시 "현행법" 만으로 설계하지 말고, 2026 하반기 개정 흡수 가능한 유연성 확보.
