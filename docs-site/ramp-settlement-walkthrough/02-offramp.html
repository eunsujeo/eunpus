오프램프 — 코인 → 법정통화 (환전)

온램프를 거꾸로 돌린 흐름이다. 코인을 소각/처분하고 원화를 입금하는데, 나가는 쪽이라 1단계에서 곧바로 잠근다

무엇·언제: 사용자가 스테이블코인을 원화로 환전합니다. 코인을 내보내는 쪽이라 1단계에서 사용가능 잔액을 곧바로 차감하면서 처리중으로 표시하고, 실제 코인 소각/처분과 원화 입금은 2단계로 미룹니다. 환전이므로 총계정상 부채가 줄어듭니다.

소각(burn)·처분 권한은 누구에게

원화코인(KRWK) 소각 = 발행사에 소각 요청(지갑 → 발행사로 코인 송금 후 소각).

달러코인(USDC) 처분 = Circle 상환(1차 시장 · 소각의 역방향) 또는 외부 거래소 매도(2차 시장).

보관 지갑(Fireblocks)은 코인을 발행사/거래소로 내보내기만 할 뿐, 소각 권한은 없습니다.

▸ Case A — 원화코인 → 원화 (발행사 소각, 1:1)

예시: 1:1 고정. 사용자가 KRWK 1,000 → KRW 1,000 환전.

    App->>DL: 미정산 1줄 — (KRWK +1,000 pending · 지갑 미출금)
    App->>GLE: 미정산 분개 — KRWK 반환채무↓ · 미정산자산↓
    App-->>Cust: "환전 처리중" 알림

    App->>JV: KRWK 1,000 전송 + 소각 요청
    JV-->>App: 소각 접수
    JV->>FB: 지갑에서 KRWK 1,000 차감 (발행사로 송금)

    JV->>JV: KRWK 1,000 소각
    App->>Acct: KRW 1,000 입금 (고객 계좌)
    Acct-->>App: 입금 완료
    App->>BL: KRWK 지갑자산 −1,000 (실제 출금)
    App->>CL: KRWK 처리중 −1,000 (사용가능은 1단계에 차감 끝 · 화면: 완료)
    App->>DL: settled
    App->>GLE: 정산 분개 — 미정산자산↑마감 · KRWK 지갑자산↓
    App-->>Cust: "환전 완료" 알림
    end

▸ Case B — 달러코인 → 원화 (Circle 상환 또는 거래소)

예시: 시세 1,310 KRW/USD. 사용자가 USDC 1 → KRW. 처분 채널 (a) Circle 상환 (b) 거래소 매도(스프레드).

핵심 포인트

  • 나가는 쪽이라 1단계 즉시 차감 — 사용가능을 바로 줄여서 같은 코인이 두 번 환전되는 일을 막습니다.
  • 원화 입금은 2단계 — 코인을 실제로 소각/처분한 뒤에야 고객 계좌로 입금됩니다.
  • 온램프의 역방향 — 부채가 줄고(↓), 발행 대신 소각/처분이 일어납니다.
