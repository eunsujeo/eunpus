9. 온·오프램프 시나리오

법정화폐와 체인 자산을 잇는 두 방향 — 순서 안전이 전부

온·오프램프는 법정화폐(fiat) 세계와 체인 세계를 잇는다. 두 세계는 확정 시점도, 되돌릴 수 있는 정도도 다르다. 온/오프램프 커넥터가 두 흐름의 순서와 증빙을 잇고, 체인 쪽은 입금·출금 시나리오를 재사용한다. fiat 정산 자체와 한도·승인은 외부 기관·정책 평면 몫이다.

9.1 온램프 (fiat → 토큰)

사용자가 법정화폐를 넣으면 토큰을 지급한다. 핵심은 fiat 입금이 확정된 뒤에만 토큰을 지급하는 것.

sequenceDiagram
    autonumber
    participant U as 사용자
    participant RAMP as 온/오프램프 커넥터
    participant BK as 은행 · PG
(외부)
    participant TX as 트랜잭션 빌더
    participant SIG as 서명 오케스트레이션
    participant CH as 블록체인
    participant IDX as 인덱서
    participant NT as 이벤트 · 알림

    U->>BK: 법정화폐 입금
    BK-->>RAMP: 입금 확정 통지
    RAMP->>RAMP: 요청 ID 로 fiat 확정 증빙 고정
    RAMP->>TX: 토큰 지급 지시(발행 또는 treasury 전송)
    TX->>SIG: 서명 요청
    SIG-->>TX: 서명된 tx
    TX->>CH: 전파
    CH->>IDX: 확정 감지
    IDX-->>RAMP: 토큰 지급 확정
    RAMP->>NT: 온램프 완료 알림
    NT-->>U: "토큰 지급 완료" webhook

Figure 9-1. 온램프. fiat 확정(2) → 토큰 지급(4~) 순서가 핵심. fiat 확정 전 토큰을 먼저 주면 미수금 위험. 온/오프램프 커넥터는 fiat 확정 증빙을 요청 ID 에 묶어 두고, 체인 쪽은 출금 시나리오(트랜잭션 빌더·서명·인덱서)를 그대로 재사용한다.

9.2 오프램프 (토큰 → fiat)

사용자가 토큰을 보내면 법정화폐를 지급한다. 핵심은 토큰 입금이 확정된 뒤에만 fiat 를 지급하는 것.

sequenceDiagram
    autonumber
    participant U as 사용자
    participant CH as 블록체인
    participant IDX as 인덱서
    participant RAMP as 온/오프램프 커넥터
    participant BK as 은행 · PG
(외부)
    participant LED as 원장
    participant NT as 이벤트 · 알림

    U->>CH: 토큰 전송(우리 주소로)
    CH->>IDX: transfer 감지 · 확정 대기
    IDX-->>RAMP: 토큰 입금 확정(CONFIRMED)
    RAMP->>BK: 법정화폐 지급 요청
    BK-->>RAMP: fiat 지급 확정
    RAMP->>LED: 토큰↔fiat 매칭 · 장부 반영
    LED->>LED: 대사(체인 입금 = fiat 지급)
    RAMP->>NT: 오프램프 완료 알림
    NT-->>U: "법정화폐 지급 완료" webhook

Figure 9-2. 오프램프. 토큰 확정(3) → fiat 지급(4~) 순서가 핵심. 토큰 확정 전 fiat 를 먼저 주면 reorg 로 토큰이 사라졌을 때 손실. 커넥터가 두 다리를 잇고 원장이 토큰 입금과 fiat 지급을 한 건으로 대사한다.

9.3 두 세계를 잇는 원칙

순서 · 멱등 · 대사
  • 확정 우선(settle-then-pay) — 받는 쪽이 확정된 뒤에만 주는 쪽을 실행한다. 온램프는 fiat 확정 후 토큰, 오프램프는 토큰 확정 후 fiat.
  • 한쪽 실패 처리 — 두 다리 중 하나가 실패/지연하면 대기(큐)·롤백·재시도를 사전에 정의한다. 동시 보장이 필요하면 양쪽 확정을 묶는 장치를 둔다.
  • 요청 ID 로 묶기 — fiat 거래와 체인 거래를 같은 요청 ID 로 연결해 원장이 단일 건으로 대사하고 사후 추적할 수 있게 한다.

9.4 컴포넌트 재사용 관계

방향fiat 다리체인 다리(재사용)
온램프커넥터 ← 은행/PG 입금 확정출금 흐름(트랜잭션 빌더·서명·어댑터·인덱서) — 토큰 지급
오프램프커넥터 → 은행/PG 지급입금 흐름(인덱서·어댑터) — 토큰 수령 확정

즉 온/오프램프 커넥터는 새 체인 로직을 거의 만들지 않는다 — 입금·출금 시나리오를 fiat 다리와 순서 안전하게 이어 붙이는 조정자다.
