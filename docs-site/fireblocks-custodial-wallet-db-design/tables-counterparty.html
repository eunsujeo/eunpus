6. Counterparty Registry

외부 송금 대상의 등록 / 검증 / 화이트리스트 — Admin Quorum 매개 사전 승인

6.1 Counterparty 종류

Counterparty (거래 상대방) = 은행이 송금하거나 송금받는 외부 대상. 종류:

  • Whitelisted address — 화이트리스트로 등록된 외부 wallet 주소 (예: 고객의 외부 wallet · 파트너 회사)
  • External wallet — 외부 자산 보관 wallet 의 매핑 (Fireblocks 외부)
  • Exchange account — 외부 거래소 계좌 (Binance · Coinbase 등)
  • Network connection — Fireblocks Network 의 다른 고객사 (chain 우회 즉시 송금 가능한 P2P 망)
  • Fiat account — 외부 fiat 계좌 (은행 송금 / SWIFT 등)
★ 모든 counterparty 등록은 Admin Quorum 매개 (사전 승인)

외부 송금 대상의 등록은 거래 위험의 진입점. 잘못 등록된 counterparty 로 송금하면 자산 회수 불가 (블록체인의 비가역성). 모든 counterparty 등록 / 회수는 Admin Quorum 매개 (mobile app 승인) 필수. 일부 종류 (whitelisted address · internal wallet) 는 Approval Group 위임 가능 (Add Validation Keys 와 같은 패턴). AML provider 사전 screening 도 권장 — 등록 전에 high-risk address 차단.

6.3 counterparty.internal_wallet_map — 은행 자체 외부 wallet 등록

은행이 직접 보유한 외부 wallet (Fireblocks 외부 storage 의 wallet) 의 매핑. 예: 은행이 별도로 운영하는 cold storage · 파트너 custodian · 자체 treasury wallet. whitelisted_destinations 와 분리하는 이유 — 고객 자산이 아닌 은행 고유 자산 의 외부 storage 이므로 운영 정책 / 권한 / 감사 추적이 다름.

6.4 counterparty.exchange_account_map — 외부 거래소 계좌 등록

은행이 거래하는 외부 거래소 (Binance · Coinbase · Kraken 등) 의 계좌 매핑. 은행은 출금 / 환전 / 유동성 공급 등의 목적으로 외부 거래소와 거래 — 각 거래소의 sub-account 식별 + 인증 정보 (API key) 가 필요. 거래소는 KR 컴플라이언스상 VASP counterparty 라 트래블룰 / KYC 의 대상.

★ 거래소 계좌의 트래블룰 함의

외부 거래소는 VASP counterparty 이므로 거래 시 트래블룰 100만원 이상 (시행령 제10조의10) 의 정보 교환 의무 적용. vasp_identifier 컬럼이 compliance.vasp_counterparty 로 cross-domain 참조 — 거래 시 자동 IVMS101 메시지 생성 trigger. 19. KR 규제 매핑 19.3.3 절 참조.
